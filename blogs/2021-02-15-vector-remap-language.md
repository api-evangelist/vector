<p><strong>Vector Remap Language</strong> (VRL) is an <a class="inline-block" href="https://en.wikipedia.org/wiki/Expression-oriented_programming_language" rel="noopener" target="_blank">expression-oriented</a>
language designed to work with observability data (logs and metrics) in a <em>safe</em>
and <em>performant</em> manner. It features a <a href="https://vector.dev/docs/reference/vrl/expressions/">simple syntax</a>, a rich
set of <a href="https://vector.dev/docs/reference/vrl/functions/">built-in functions</a> tailored to observability use cases,
and <a href="#features">numerous features</a> that set it far apart from other options.
This <a href="https://vector.dev/releases/0.12.0/">0.12</a> release of Vector marks the official release of the language.</p>

<li>A new OpenTelemetry sink is now available. You can find a
<a href="https://vector.dev/docs/reference/configuration/sinks/opentelemetry/#quickstart">quickstart guide here</a>.
<ul>
<li>We have more plans here such as gRPC support and smart grouping at the sink.</li>
</ul>
</li>
<li>We introduced a new exclusive route transform. You can read more in our
<a href="https://vector.dev/highlights/2024-11-07-exclusive_route/">release highlight</a>.</li>
<li>Apple Silicon builds are now available in our <a href="https://vector.dev/download/">downloads page</a>.
Note that these are available since <code>v0.44.0</code> and won&rsquo;t show up for older versions.</li>
<li>A new type of <code>enrichment_table</code>, called <code>memory</code>, was introduced! This table can also function as a sink and addresses several new use cases. See this
<a href="https://vector.dev/highlights/2025-02-24-memory_enrichment_table/">release highlight</a> for details.</li>
<li>The VRL function library keeps growing thanks to community contributions! You can read more:
<ul>
<li><a href="https://vector.dev/releases/0.44.0/#new-features">0.21.0 Features</a></li>
<li><a href="https://vector.dev/releases/0.43.0/#new-features">0.20.0 Features</a></li>
</ul>
</li>
</ul>
